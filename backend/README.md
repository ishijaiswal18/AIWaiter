# AIWaiter Backend

This is the backend for the AIWaiter application, built with Node.js and Express, following an MVP architecture.

## Setup

1.  Install dependencies: `npm install`
2.  Set up environment variables in a `.env` file (see `utils/config.js` for required variables).
3.  Start the server: `npm start` (or `npm run dev` if configured for development).
