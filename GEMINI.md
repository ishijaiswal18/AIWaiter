# AIWaiter: A Voice-Enabled Restaurant Ordering System

Welcome to the AIWaiter project! This application is a voice-enabled restaurant ordering system that allows users to interact with a virtual waiter to place orders, get recommendations, and more.

## Project Overview

The AIWaiter application is composed of three main components:

1.  **Backend (`/backend`)**: A Node.js and Express application that serves as the backbone of the system. It provides a RESTful API for managing menu items, orders, and users. For more details, see the [Backend Documentation](./backend/GEMINI.md).

2.  **Frontend (`/frontend`)**: A React and Vite single-page application (SPA) that provides the user interface for the application. It features a modern and intuitive design, with components for displaying the menu, managing the cart, and interacting with the AI voice agent. For more details, see the [Frontend Documentation](./frontend/GEMINI.md).

3.  **AI Voice Agent (`/AIVoiceAgent`)**: A Python-based voice agent that uses the `livekit-agents` framework and the Gemini Realtime LLM to provide a natural and conversational user experience. The agent can understand and respond to user requests in real-time, making it a powerful and intuitive way to interact with the application. For more details, see the [AI Voice Agent Documentation](./AIVoiceAgent/GEMINI.md).

## Getting Started

To get started with the AIWaiter application, please refer to the documentation in each of the subdirectories. Each `GEMINI.md` file contains detailed instructions on how to set up and run the corresponding component.
